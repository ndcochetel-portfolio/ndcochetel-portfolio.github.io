02 · Beyond genomes

The graph layout

Sequence graphs, bioinformatics pipelines and AI agent workflows share one structure: steps or sequences as nodes, and each genome, sample or run as a path through them. The way I reason about one carries over to the others.

Genomics

Pangenome graph

Each genome is a path. Shared sequence is stored once, and variants open bubbles.

Pipelines

Workflow graph

Each sample is a path through the same processes. Nextflow caches, retries and records where every file came from.

AI agents

Agent graph

Each run is a path through plan, draft and check steps. Runs diverge where the agent decides differently, or skip a step.

What carries over
Paths, not copies
Compare runs the way you compare genomes: by where their paths share nodes and where they split.
Divergence is the signal
A bubble in a pangenome and a branch between two agent runs both point to where to look first.
Layers on the graph
Expression and methylation on a genome graph; cost, latency and errors on a workflow graph.
Provenance
Every output traced back to the path that produced it, which is what makes results reproducible.
